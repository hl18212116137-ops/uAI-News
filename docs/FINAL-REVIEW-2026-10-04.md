## 清理与修正

- 删除失效脚本 `scripts/bootstrap-fetch-defaults.ts`、空信息流演示新闻模块 `lib/demo-feed-posts.ts`，以及未引用的导出、重复来源简介辅助函数、旧解读缓存写入接口和无用类型。仍兼容读取历史解读缓存。
- 空数据库返回真实空列表；访客来源列表不再伪造不存在的来源。保留真实推荐来源目录、新来源添加、订阅、分类、收藏、解读、长文和个人阅读偏好。
- 已暂停的信息源不会因普通用户订阅或重复添加而重新启用；订阅记录的 handle 取数据库原值。重复订阅使用数据库冲突更新，来源查找忽略大小写。
- 添加来源时严格校验 X / Twitter 域名和用户名，拒绝伪造子域名、非 HTTP 协议、携带认证信息或异常端口的 URL。
- 抓取任务记录所有者；查看状态、取消任务均要求本人登录。旧抓取和处理接口要求管理员身份，不能从客户端冒用 userId 或 taskId。单源抓取在阶段和批次边界响应取消，已启动的当前批次可能先完成。
- 注册接口验证并规范邮箱，校验昵称与密码长度，拒绝超过 bcrypt 72 字节限制的密码；并发注册同一邮箱只创建一个账号。
- `typecheck` 纳入 `scripts/**/*.ts`，修复中文回填脚本的可空类型问题。设计令牌和页面布局没有调整。
