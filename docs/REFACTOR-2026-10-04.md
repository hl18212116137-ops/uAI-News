# 2026-10-04 网站重构与验证记录

这是初始重构阶段的历史记录；后续数据库验证、依赖升级与远程整合结果见 [合并检查记录](MERGE-REVIEW-2026-10-04.md)。

## 交付范围

本轮针对 Next.js 网站完成清理、核心状态拆分、数据访问与去重性能重构。保留原有主列、两侧面板、分类栏、弹窗和视觉语言；未修改独立 `mobile-app/` 项目，也未写入配置的数据库或触发付费抓取。

当前目录没有 Git 历史，因此修改前已保存源码、配置与数据快照：

`../uAI-News-before-refactor-20261003.tar.gz`（文件权限 0600）。

快照不含可重新生成的依赖与构建目录。若需恢复，请先解压到独立目录对照，不要直接覆盖现有工程。

## 清理

- 初始清理共 1,786 个文件，约 **182.08 MiB**：旧构建运行目录、临时日志、历史 JSON 数据/备份、过期类型补丁、未使用 Providers 和调试写日志 API。
- 逐路径记录见 [cleanup-manifest.json](cleanup-manifest.json)。
- 保留 `data/sources.json`；它确实被来源资料模块读取，并修复了 Docker 忽略该源码依赖的问题。
- 删除无引用的局部常量、重复翻译函数、永远返回空列表的网页抓取占位请求，以及失效的环境配置示例。
- 修复 `fetch` / `process` 指向不存在脚本的问题；新命令直接复用 ingest/process 服务。
- 实际框架为 Next.js 15.5.19，修正 README 和架构文档中的 Next.js 14、SQLite、Supabase Auth 等过期描述。

## 架构与行为变化

| 部分 | 结果 |
|---|---|
| 首页客户端 | MainContent 从 2,049 行降至 1,109 行，保留布局并通过独立 hooks 组合分页、解读、长文、刷新、滚动、通知和新增标记 |
| 服务端首页 | `home-service.ts` 统一装配数据，首屏复用已加载 feed，RSC 边界仅负责传递 DTO |
| 数据转换 | 订阅流与详情共用新闻列选择和行转换；来源列表 DTO 收敛到 `lib/types.ts` |
| 去重 | 每条内容只解析一次 token，倒排索引缩小比较候选；保留原精确去重及事件窗口规则 |
| 分页 | 采用服务端 nextOffset；筛选从 0 开始，旧请求取消，预览之外的全文匹配仍可展示 |
| 解读/长文 | 修复解读重试不请求、长文失败自动无限重试；卸载/切换时取消过期请求 |
| 乐观更新 | PASS 失败只恢复对应帖子；旧用户收藏请求不会回滚到另一用户的状态 |
| 任务轮询 | 单请求串行执行，失败退避、过期停止、可取消，清理定时器与在途请求 |
| 数据库 | 连接池跨热重载复用，增加查询超时；两个计数查询合并为一次条件聚合 |
| 加载与运行 | 取消多个未打开面板的定时预加载；启动时只同步静态资源，不再复制整套 standalone 依赖 |

新增 `FEED_CANDIDATE_LIMIT` 默认 **1000**、范围 **100–5000**，限制每次信息流查询和评分的候选范围。列表总数与筛选范围针对当前候选快照，窗口外的历史内容保留在数据库。仍使用 offset 分页；后台数据变更后刷新第一页，不保证跨变更的不可变快照。

## 验证证据

最终执行 `npm run check` 成功，包括：

- 源码 TypeScript 检查，并启用 `noUnusedLocals` / `noUnusedParameters`。
- **16 项回归测试通过**：默认页大小、全文筛选与预览、分页偏移、原/新去重一致性、候选上限、来源大小写缓存、解读重试、请求取消、长文失败恢复、筛选竞态、服务端全文匹配、轮询防重叠与终止。
- Next.js 生产构建通过，包含框架生成的路由类型检查；没有跳过构建错误。
- 基于 TypeScript 解析的依赖遍历未发现未被页面/API/运维脚本引用的源码模块。
- `npm run fetch -- --help` / `npm run process -- --help` 正常退出，不调用外部服务。

浏览器检查：

- **1440×1000 桌面首页、390×844 移动首页**：相同空数据基线下，重构前后 PNG **逐字节一致**。
- 信息源侧栏可展开/折叠，搜索 `Karpathy` 后列表只保留对应来源。
- 登录弹窗可打开和关闭。
- 长文查询失败时显示错误与重试入口；失败不会触发循环请求。
- 检查期间无浏览器未捕获错误。

HTTP 检查：未登录访问 `/api/bookmarks`、`/api/me/subscribed-feed`、`/api/me/subscribed-sources` 均为 401；失效任务为 404。数据库离线时长文接口返回 500 并由 UI 展示错误，公共 feed 继续沿用既有空列表回退。

## 性能测量

| 指标 | 重构前 | 重构后 |
|---|---:|---:|
| Next 构建报告：首页 First Load JS | 140 kB | 139 kB |
| 1,000 条合成新闻去重，保留结果完全相同 | 5,053.07 ms | 7.11 ms |

去重数据为一次本机 CPU 微基准，含预热；不是生产流量、数据库查询或整页 LCP 测量。不同文本重复程度会改变倒排索引候选数量，不能把这个倍率当成整站加速倍率。可通过 `npm run benchmark:feed` 复现。

`app/globals.css`、`tailwind.config.ts` 与两份原有 `.env*.local` 的内容和快照一致。

## 尚未验证的外部边界

配置的 PostgreSQL 连接返回 **ECONNREFUSED**。因此未验证真实数据库查询执行计划、真实登录后的收藏/订阅写入、AI 分析生成和外部抓取流水线，也未进行生产压力测试。单元测试、匿名 API 和空数据页面验证不能替代这些检查。

内存任务状态与部分限流仍只适用于单实例；多实例部署需共享任务存储。此轮未升级框架大版本，也未执行远程数据库迁移或发布部署。
