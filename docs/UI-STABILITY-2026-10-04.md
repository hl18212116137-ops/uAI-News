# 页面与弹窗稳定性检查

## 发现及修复

- 首页原骨架屏使用固定 256px 左栏、72px 占位顶栏与 896px 内容宽度，实际页面使用 56px 顶栏和 800px 内容栅格。两阶段几何不一致导致刷新时换位。现在骨架复用主区栅格、标题与统计尺寸；收藏、文章、管理页各有自己的加载占位，避免套用首页骨架。
- 阅读偏好在加载提示出现、消失时改变面板高度；隐藏记录从四条骨架切为空态时也会明显收缩。现在异步内容弹窗使用受视口约束的稳定面板高度，内容在面板内滚动，偏好状态提示复用同一行。添加来源同样固定面板高度，避免推荐列表加载后撑大弹窗。
- 焦点进入、Tab 循环、关闭后的恢复均使用 preventScroll，避免焦点切换带动滚动容器。文档预留滚动条空间；弹窗出现时停用首页的背景滚轮转发，面板滚动不向外串联。
- 首页内联重试回调会使 NewsList 的 memo 每次失效，现已稳定回调。登录入口不再依赖整个布局上下文对象。常用弹窗在入口 hover/focus 时预加载，保留动态拆包；阅读偏好不再额外等待一次 effect 才挂载。
- 登录表单 Suspense 占位按真实表单结构排版，避免 280px 通用占位被真实内容替换时改变布局。

## 验证

- TypeScript 与 Next.js 15.5.27 生产构建通过；首页 First Load JS 仍为 141 kB。
- 49 项单元测试通过。新增背景滚轮在弹窗期间暂停、关闭后恢复的回归测试，并加强焦点恢复不自动滚动的断言。
- 首页与 feed、长文、推荐来源、health smoke 通过；本地数据库为空时 health 的 503 为缺少资讯，不是连接失败。
- 使用只转发到本地应用的临时代理，将偏好/隐藏记录响应延迟 1.8 秒。阅读偏好在 390×844 视口下，加载前后 clientHeight 均为 538px、offsetTop 均为 152px；document scrollWidth 为 390px。隐藏记录在 1280×720 下加载前后 clientHeight 均为 617px、offsetTop 均为 50px。
- 浏览器巡查：首页刷新、偏好打开/关闭、隐藏记录加载、来源侧栏与添加弹窗、收藏导航与刷新、登录与注册页面、文章空态、普通用户访问管理页的权限拦截。控制台未捕获 warning/error。

本轮验证基于本地生产构建，未发布线上。没有执行真实内容抓取、生成或写入账号偏好；当前本地没有新闻，文章实内容及管理员登录后的页面尚未浏览器验证。固定布局与模拟慢接口的结果不代表线上数据库延迟、真实设备帧率或完整 Web Vitals 已经测定。原有视觉语言、布局逻辑和登录数据保留。
