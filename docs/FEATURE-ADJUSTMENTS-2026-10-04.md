# 2026-10-04 功能精简与调整

依据功能审查实施。保留资讯流、订阅、分类、收藏、账号、AI 解读和长文阅读；主列、侧栏、卡片、颜色、字体与统一弹窗动画保持现有规范。`app/globals.css`、`tailwind.config.ts` 未修改。

## 功能变化

| 原功能 | 调整结果 |
|---|---|
| 通用流水线规则编辑器 | 删除 1,861 行旧面板；个人端仅保留阅读天数、屏蔽关键词、优先关键词 |
| 顶栏 PASS 与采集设置 | 收敛为「阅读偏好」；个人隐藏记录从偏好面板进入 |
| PASS 恢复 | 改为「不感兴趣 / 恢复」；只更新当前用户反馈，不重新生成或覆盖共享文章 |
| 采集参数、源开关、审核、长文导入 | 集中至 `/admin/pipeline`，服务端校验管理员身份 |
| 添加信息源、长文目录拖动 | 移除拖动状态和事件，保留固定位置、目录跳转与折叠 |
| 固定「专业版」与演示解读 | 删除固定会员标识及生产解读中的预制答案 |
| 首页统计 | 保留信息源和滚动近 24 小时新增；信息源计入全部类型；移除专题、全库累计等无用项 |
| 无内容页面 | 区分无内容、筛选为空、实际更新中和服务不可用；错误提供显式重试 |
| 自动工作 | 浏览或读取订阅不触发抓取；自动长文发现默认关闭 |

## 完整性修复

- 普通用户无法通过 API 绕过管理页：URL/文件导入、全站源修改/删除、采集审核限定管理员；添加源与现有新闻长文提取至少需要登录。
- 历史停用规则保留，但不能继续新增，也不占用阅读偏好容量。时间窗口替换采用事务与用户范围锁，失败保留旧值，并发保存只留下一个窗口。
- 注册时初始化默认订阅；取消最后一个订阅后，首页不再擅自补回默认订阅。
- 隐藏、恢复、再次隐藏按最新用户操作生效；其他用户不能读取或恢复自己的隐藏记录。恢复面板每次打开重新读取，批量最多 30 条。
- 所有共用弹窗支持键盘焦点边界、Escape 和关闭后焦点恢复；不同弹窗使用独立 key，修复数据刷新导致重复遮罩的问题。
- `/api/feed` 与 `/api/me/subscribed-feed` 在空结果且数据库不可用时返回 503，不再用空成功响应掩盖故障。

## 运行与回滚

当前目录无 Git。修改前备份位于 `../uAI-News-before-feature-adjustment-20261004.tar.gz`，权限 0600；不含依赖、生成目录和环境密钥。恢复时先解压至独立目录对照。

本地服务运行在 `http://localhost:3001/`。原 `.env.local` 未修改，实际数据库目前连接被拒绝，因此首页如实展示不可用状态。真实抓取、付费 AI 生成、真实账户历史数据和生产负载未验证。没有执行远程迁移或部署。

验证使用独立临时数据库 `uai_feature_test`，结束后删除测试容器并恢复 Docker Desktop 原先的停止状态；测试服务器已停止，生成的数据缓存已清除，避免临时数据残留在本地站点。

数据库测试使用 `TEST_DATABASE_URL`，只接受本机名为 `uai_feature_test` 的库：

```bash
TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:PORT/uai_feature_test npm run test:integration
```

HTTP 测试另需在 `127.0.0.1:3104` 启动连接同一隔离库的服务，设置独立 `NEXTAUTH_SECRET`，并将测试用户 `00000000-0000-4000-8000-000000000001` 加入 `PIPELINE_ADMIN_USER_IDS`。执行时传入 `TEST_BASE_URL=http://127.0.0.1:3104`、相同的 `TEST_AUTH_SECRET`。测试库账号由数据库测试初始化。建议使用独立 `NEXT_DIST_DIR` 构建和启动验证服务，避免和正常网站共享生成缓存。没有测试配置时集成测试跳过，不读取实际数据库配置。
