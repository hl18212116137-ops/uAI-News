## 部署与已知边界

- PostgreSQL 需要 `refresh_tasks` 表。已有远程版本已提供 [迁移](../db/migrations/add-refresh-tasks.sql)；缺表的旧环境应先执行该幂等迁移。本轮只将角色权限语句改为兼容普通 PostgreSQL，保留 RLS，并撤销 PUBLIC 及存在的 anon/authenticated 角色权限，不开放 Data API 访问。
- 任务状态跨实例持久化，后台执行保留 `after()`；这不等同于带崩溃恢复和自动重投的持久作业队列。部分进程内冷却/限流也不等于分布式限流。
- 完整依赖审计仍有 5 项 high 包告警，均沿 Tailwind 3 构建链指向同一未修复的 braces 问题。生产依赖审计为零；没有为消除开发依赖提示强制迁移 Tailwind 4。详见 [全部依赖](audits/2026-10-04-merge/all-dependencies-audit.json)、[生产依赖](audits/2026-10-04-merge/production-audit.json) 和 [上游公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。
- 实际本地数据库目前无来源、无新闻，空状态符合数据现状；feed health 因缺少新闻返回 503，数据库查询正常。
- 未调用真实付费抓取、AI 生成、第三方长文提取，也未进行生产流量压力测试。合并通过不代表这些外部服务已验证可用。
- 本地环境配置、数据库、独立 mobile-app 项目以及父目录备份不纳入 Git 提交。
